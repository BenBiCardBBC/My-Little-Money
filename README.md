# 我的小金库 · My Little Money

一个本地优先的个人资产管理与记账 Web 应用。它帮助你统一管理银行卡、电子钱包、现金、投资和负债账户，并在浏览器中安全地记录日常流水。

> 当前版本：`v1.0.0`

## 特性

- 中文响应式界面：桌面端侧边导航、移动端底部导航。
- 资产总览：总资产、总负债、净资产、本月收支、账户分布和最近流水。
- 账户管理：银行卡、支付宝/微信、现金、基金、股票、信用卡、其他资产和其他负债。
- 卡号保护：银行卡和信用卡仅保存、展示卡号后四位。
- 余额维护：支持新增账户、手动修改余额（二次确认）及删除账户；删除时会提示关联流水的影响。
- 记账中心：收入、支出与转账；每一笔操作都会正确更新账户余额。
- 分类与备注：根据历史记录提供自动建议；可直接输入新分类或备注。
- 流水检索：按分类或备注关键词筛选。
- 本地备份：导出和恢复完整 JSON 数据备份。
- 流水导出：支持全部、日期范围或分类筛选，可生成 TXT 或 PDF 文件。
- 本地优先：数据存放在浏览器 IndexedDB 中，不接入真实银行账户，也不上传到服务器。

## 技术栈

- [Next.js](https://nextjs.org/)
- TypeScript
- Tailwind CSS
- [Dexie](https://dexie.org/) / IndexedDB
- [jsPDF](https://github.com/parallax/jsPDF)

## 快速开始

需要先安装 Node.js 20 或更高版本。

```bash
git clone <your-repository-url>
cd my-little-money
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

## 可用命令

```bash
# 启动本地开发服务器
npm run dev

# 创建生产构建并执行 TypeScript 检查
npm run build

# 启动生产服务器（需先执行 build）
npm run start
```

## 数据与隐私

本项目不会连接银行、支付平台或第三方账户。所有账户及流水通过 IndexedDB 保存在当前浏览器的本地存储空间中。

请注意：清理浏览器站点数据、使用隐私浏览模式，或在另一台设备上打开应用，都不会保留当前数据。建议定期使用右上角的“备份”功能下载 JSON 备份文件；可通过“恢复”导入。

## 使用说明

### 账户

1. 打开“账户”页，选择“添加账户”。
2. 对银行卡或信用卡填写卡号后四位，信用卡余额会按负债自动处理。
3. 使用“修改余额”直接校正账户数值；系统会在提交前要求确认。

### 记账

1. 打开“记账”页，选择收入、支出或转账。
2. 填写金额、账户、分类、日期和可选备注。
3. 转账必须选择不同的转入、转出账户，两个账户余额会同步变化。

### 导出流水

在“记账”页右下方的导出面板中：

1. 选择全部、按时间或按分类。
2. 按需填写日期范围或分类关键字。
3. 选择“文字”下载 TXT，或选择“PDF”下载可阅读的报表。
